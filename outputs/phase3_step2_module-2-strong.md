# Payment Tracker Dashboard

> PREVIEW after a founder override against the evidence at Gate 1 and Gate 2: demand not yet proven.

This module gives you a single spreadsheet to log every invoice, due date, reminder sent, and payment received so you can see the status of all accounts at a glance. Use it daily to decide which clients need a nudge and which invoices are already settled.

## Checklist

- [ ] Create a new spreadsheet using the provided template columns
- [ ] Enter each active invoice with client name, invoice number, amount, and due date
- [ ] Record the date you send the first reminder for each invoice
- [ ] Log any follow‑up reminders with date and channel used
- [ ] Mark the payment received date and amount when funds arrive
- [ ] Update the status column to reflect current state (e.g., Pending, Reminded, Paid)
- [ ] Filter or sort by due date to spot overdue items quickly
- [ ] Review the dashboard each morning and prioritize outreach for overdue invoices
- [ ] Archive fully paid invoices to a separate sheet each month
- [ ] Back up the tracker to cloud storage weekly
