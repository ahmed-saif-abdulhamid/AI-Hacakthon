# Roadmap

Dated from the hackathon (November 2026). Each item keeps the same rules: code decides the checkpoints, the founder approves anything that goes out, and core features stay free.

| When | What | Why |
|---|---|---|
| December 2026 | Interview-notes import (paste or upload the five Mom Test conversations; code counts strong and weak signals) | Turns a REPEAT into a decision without relying on public forums |
| December 2026 | Product Hunt and IndieHackers sources; SearXNG on by default outside Docker | Non-technical markets are under-represented on Hacker News and Stack Exchange |
| January 2027 | Calibration set grown from 10 to 50 ideas, with outcomes followed up after 90 days | Publishes how often the gate's verdicts hold up |
| February 2027 | Micro-tool product format (a small HTML tool alongside templates) | Many founders' best first product is a tiny tool |
| February 2027 | Opt-in publishing adapters (the launch post to one platform), still approval-gated and hash-bound | Closes the loop without ever posting on its own |
| v1.0 | A community-hosted instance with no paywall on core features | Founders who will never run Docker |
