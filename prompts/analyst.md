# Analyst agent (STUBBED)

Phase 6 operate-and-learn memo. The interface is documented for future work: the analyst receives only real metrics (real sign-ups, real orders, refunds, support requests) and writes a persevere-or-pivot memo with every statement citing a metric. Below the pre-registered thresholds it must say "Not enough data to call persevere or pivot." In this version the memo is produced by code, not by a model.
